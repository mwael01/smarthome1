Two-Layer AI-Integrated Multi-Camera Intrusion Detection (2024)
Part of: A Literature Survey on Multi-Sensor Face-Recognition-Based Smart Home Security Systems

# 1. Bibliographic Reference

B. D. Kaur, X. Sun and J. Dai, “A Two-Layer AI-Integrated Multiple-Camera System for Detecting Human Intrusions,” in Intelligent Systems and Applications, Springer, 2024.

# 2. Problem Addressed

Conventional residential alarm systems rely on many sensors that are inconvenient to manage and produce large volumes of continuous video that overwhelm homeowners and raise privacy concerns.

# 3. Method / Algorithm

A two-layer architecture: a first layer performs AI-based detection of strangers and selected objects (e.g., weapons); a second layer enables cross-camera tracking to monitor suspicious behaviour. The design reduces the need for continuous high-volume recording.

# 4. Strengths

Addresses both detection accuracy and practical usability/privacy issues. Demonstrates cross-camera coordination. Suitable for residential environments.

# 5. Limitations / Weaknesses

System complexity increases with the number of cameras. Evaluation is still limited compared with large-scale surveillance benchmarks. Integration with face-recognition identity verification is left for future work.

# 6. Relevance to the Proposed Project

Supports the project’s multi-camera and motion-triggered design philosophy and highlights the value of hierarchical processing (cheap motion/AI filter followed by more expensive recognition).

# 7. Key Takeaway for Future Improvement

Layered AI processing across multiple cameras can improve coverage while controlling data volume and privacy impact—an important consideration for a practical smart-home system.
