Deep Learning for Face Anti-Spoofing: A Survey (2023)
Part of: A Literature Survey on Multi-Sensor Face-Recognition-Based Smart Home Security Systems

# 1. Bibliographic Reference

Z. Yu et al., “Deep Learning for Face Anti-Spoofing: A Survey,” IEEE Transactions on Pattern Analysis and Machine Intelligence, 2023.

# 2. Problem Addressed

The literature on face anti-spoofing had become fragmented; a comprehensive taxonomy covering supervision signals, domain generalisation and multi-modal sensors was needed.

# 3. Method / Algorithm

Systematic review of deep-learning FAS methods, organising them by supervision type (binary vs pixel-wise auxiliary), evaluation protocol (intra-dataset, cross-dataset, domain generalisation, open-set), and sensor modality (RGB, depth, IR, multi-modal).

# 4. Strengths

Provides a clear taxonomy, highlights the importance of domain generalisation, and catalogues public datasets and evaluation protocols. Serves as an authoritative reference for the state of the field up to 2023.

# 5. Limitations / Weaknesses

As a survey it does not propose a new algorithm. Rapid subsequent progress (transformers, foundation models) continues to evolve the landscape.

# 6. Relevance to the Proposed Project

Gives the project team a structured understanding of the anti-spoofing design space and the evaluation practices expected in modern research.

# 7. Key Takeaway for Future Improvement

Domain generalisation and open-set evaluation are the current frontiers; any practical system should be tested beyond the dataset on which it was trained.
This individual survey paper is one of twelve companion documents that support the main overview paper “A Literature Survey on Multi-Sensor Face-Recognition-Based Smart Home Security Systems.”
